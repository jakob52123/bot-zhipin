# 隐私说明

这页说明你逛 Bot 直聘、搜索或投稿时，我们会记下什么、不记什么，以及这些记录存多久。

## 逛网站时记什么

为了知道哪些 Bot、Prompt、Skill 有人用，我们会记下你在站内的一些访问情况。这些记录存在本站自己的数据库里，只有维护者能看，不交给任何第三方。

- 打开了哪个页面（只记路径，地址里 `?` 和 `#` 后面的部分不记）。
- 从哪个网站点进来的（只记对方的域名），以及链接里带的 utm 来源标记。
- 大概在哪个国家或地区（两个字母的代码，由帮网站做托管和网络转发的平台 Cloudflare 提供），用的是手机还是电脑。
- 在页面上点了什么：导入、复制、搜索、筛选、点开外部链接、投稿走到了哪一步。
- 搜索框里输入的词（处理方式见「搜索词」一节）。
- 网页里没有第三方统计、广告或跟踪代码。
- 自动程序（爬虫、无头浏览器）的访问不记。

## 不记什么

我们认得出今天来过的是同一位访客，但认不出你是谁，也连不起你不同日子的访问。

- 不记 IP 地址，也不记浏览器标识的原文。
- 不用 cookie（网站存在你浏览器里的小条记录）认人，没有跨网站追踪。
- 区分访客的办法：服务器把「IP + 浏览器标识 + 当天日期」加上一个只有服务器知道的密钥，算出一串摘要，只留前 16 位，当作「当天的访客号」。第二天日期变了，就算不出同一个号，所以没法把同一个人不同日子的访问连起来。
- 会话号存在浏览器的 sessionStorage（浏览器给当前标签页准备的临时储物格）里，关掉标签页就没了；闲置 30 分钟或者过了零点，会换一个新的。

## 搜索词

别在搜索框里输入名字、公司这类你不想留下的信息。

- 搜索词最多存 40 个字。
- 里面的邮箱会换成「【邮箱】」，7 位以上的数字（手机号、证件号这类）会换成「【数字】」。
- 原文保存 90 天，之后删掉原文，只留下「这里有过一次搜索」的记录。

## 存多久

- 访问记录保存 400 天，满了就清掉。
- 搜索词原文保存 90 天。
- 热度数字（导入、复制安装提示词、复制开场白、复制口令被点的次数）：同一个网络地址 24 小时内对同一个 Bot 重复点，只算一次；去重只存 IP 的摘要，过了 24 小时就清掉。
- 防刷用的计数（按 IP 摘要或账号计）：时间窗口最长一天，过期就清掉。

## 投稿时

- 投稿要用 GitHub 登录。网站只拿你的 GitHub 用户名和数字 ID，不申请读写你仓库的权限；GitHub 给的授权令牌拿到用户名后马上作废，不保存。
- 登录状态存在一个 cookie 里，2 小时后失效；登录跳转时还有一个 10 分钟就失效的临时 cookie。本站自己只设这两个 cookie。
- 网站会记下投稿人的 GitHub 数字 ID 和 PR 编号，用来限制同时在审的投稿数量，以及确认来更新 Bot 的是原作者。
- 投稿内容会作为 PR 公开在 GitHub 仓库 `jakob52123/bot-zhipin` 里，任何人都能看到。所以别放密钥、内部链接、手机号、别人的聊天记录；校验会扫描密钥，看到疑似手机号、邮箱、身份证号也会提醒你。
- 作者主页上的头像由本站转发，看主页的人不会直接连到 GitHub。

## 导入 Bot、安装 Skill 时

- 网站托管在 Cloudflare，访问会经过 Cloudflare 的网络。
- 点「导入」会打开 Grok Bot App 或 x.ai 的页面，之后的事归 x.ai 和 Bot 作者。Bot 的内容由作者在 x.ai 上维护，导入时拿到的是作者当时的版本。
- OpenBot 的 Bot 没有「导入」。点「复制安装提示词」只是把一段话放进你的剪贴板，网站不会连你的电脑。你把这段话发给 OpenBot 以后，它会读本站仓库里这个 Bot 的文件；照着开源项目做的 Bot，装的时候还会下载那个项目的最新版，在你自己的电脑上跑。之后的事归 OpenBot、你选的 AI 和项目作者。
- 每个 Bot 的详情页列出它会用到的权限：云电脑文件、本机文件、浏览器 Cookie、外部账号、联网、定时自动运行、代我发消息。卡片上会标出「要连账号」「会自己跑」「会代你发消息」。导入前，Grok Bot App 也会列出它要建的例行任务和要连的应用。
- 我们收录时记下了审过的模板版本，每天核对一次；作者改过模板，就先复核，有问题就下架。OpenBot 的 Bot 照着的源项目也一样：我们记着审过的那次提交，作者之后改了，第二天会收到提醒去复核。
- Skill 的安装命令直接从作者的 GitHub 仓库装最新版。我们记着审过的那次提交，作者之后改了这个 Skill 的文件，我们第二天会收到提醒去复核。
- 给 AI 用的 bot-zhipin skill 只下载本站公开的目录数据，在你自己的电脑上搜索，不会把你搜的内容发给本站。

## 浏览器里存了什么

- 会话号：存在 sessionStorage 里，关掉标签页就没了。
- 小队页会在你的浏览器里用 localStorage（浏览器留在你设备本地的储物格，关掉标签页也还在）记住哪些成员已经点过导入，方便你接着装，不会发给本站。
- 投稿登录时的那两个 cookie（见「投稿时」一节）。

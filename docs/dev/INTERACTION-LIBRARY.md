# Prompt / Skills 交互规格

这是 [INTERACTION.md](INTERACTION.md) 的分册，描述两个维护者收录库的浏览、搜索与复制交互，以仓库代码和 e2e 用例为准。

## 一、入口与路由

品牌后的 Bot（`/`）、Prompt（`/prompts/`）、Skills（`/skills/`）是普通链接，不是页内标签。点模块入口到不带筛选的列表；进入 `/prompts/<slug>` 或 `/skills/<slug>`，仍在所属入口显示底板并标记 `aria-current="page"`。Bot、小队、专题及作者页归 Bot；投稿页和未找到页不选中模块。两库都不接受投稿（决策 46）。

窄于 768px 时三个模块都留在导航上，只收起工具；极窄屏保留站标和可访问名。菜单展开后可 Tab 到工具，点岛外或切回桌面关闭，按 Esc 关闭并还焦菜单按钮。

**全站查找（决策 71，#38）。** ⌘K / Ctrl+K 打开搜索面板。空查询只列 Bot、小队；输入后依次列有命中的 Bot、小队、Prompt、Skills，各最多 8、3、4、4 条。库条目显示分类砖、标题、用途和分类标签；组名吸顶，上下键跨组移动，回车或点击进对应详情。面板优先匹配显示标题，其次分类、作者及别名（原标题、Skill 原名、slug），再是用途、标签和适用工具，最后才是场景。英文别名按词首匹配，不搜正文。

`SearchPalette.vue` 在首次打开时才加载轻量索引，成功后复用。数据未到不抢当前选中项，也不提前显示无结果；数据块失败则尝试 `/data/index.json`，只取两库条目并将详情地址转成站内路径；两者都失败，下次打开再试。

## 二、列表

`LibraryPage.vue` 左栏是库名、「共 N 条」、本库搜索和分类；右栏是连续的条目行，不是两列卡片（决策 61）。行首是分类砖，中间是标题与用途，宽屏行尾是作者；日期、许可不占列表位置。

- **Prompt 直接使用（决策 64，#30）：** 标题进详情，点正文可以选词。行首复制按钮复制完整正文，不是可见片段。有译文时列表只带译文，否则带原文。`PromptSnippet.vue` 根据实际换行判断是否超过四行，短文没有展开开关；长文可原地展开，展开后工具条可收起或复制全文。收起时若行首已滚出视口，就滚回行首。以文本而非 HTML 渲染，高亮【占位符】、花括号以及含汉字且内部不超过 30 个字符的尖括号占位符，普通英文标签不染色。
- **媒体 Prompt（决策 69，#34）：** 「出图」「视频」是独立分类。若有效果图，第一张作为缩略图链接到同一详情；桌面与正文片段顶部对齐，窄屏排在片段下。没图不留空位。无正文的条目标「仅摘要」，此标签单独链接出处，不给片段、展开或复制按钮。
- **Skills（决策 65，#31）：** 标题旁列原名，整行可进详情，右侧是作者而非适用工具。列表不显示安装命令、正文或示例；适用工具留给详情。

**筛选与返回。** 分类取「全部」加库中确有条目的分类，保持枚举顺序。查询在本地即时匹配，中文输入法组词完成再筛选；页面激活前输入的文字也保留。字段包括标题、原标题或原名、分类、用途、场景、标签、作者、适用工具，以及 Prompt 供复制的那一份正文，不含安装命令。经 NFKC 归一化、不分大小写，每个词都要在至少一个字段中命中，不同词可来自不同字段。与面板共用拆词规则，例如「做PPT」等同「做 PPT」，「B站」也能匹配「B 站」。

先按查询算各分类数字，再取选中分类的交集作为行数和「共 N 条」；查询后降为零的分类仍可选。固定按收录日期降序，同日按 slug 的 FNV-1a 32 位无符号散列升序，筛选不重排、不分页（决策 47）。地址只保留非空的 `q` 和有效的非默认 `cat`，以 replaceState 更新，不为逐字输入堆历史。直达、刷新和历史导航按地址恢复；详情链接带条件，「返回」链接回同库同条件，无参数则回裸列表。零结果保留控件，显示「没有找到」；点「看看全部」清条件并还焦搜索框，空库也可重置。

## 三、详情

`LibraryDetail.vue` 在桌面左栏放返回、分类砖、操作和属性，右栏从分类、标题、可选原名和一句用途开始。属性依次为能用在（Skill 的工具或 Prompt 的适用模型）、作者、许可证及可选原版权行、收录日期。无作者或许可链接时只给文本；`LibrarySource.vue` 的出处链接新标签打开，隔离 opener 和 referrer。

**Prompt（决策 63，#29）。** 收录时放原文，英文配本站中文译文；不再依据许可枚举决定页面是否显示正文。保留署名、许可及精确来源，作者要求撤下则下架。有图先列「效果图」，逐张标注出处或生成说明，保留比例，可打开原图。然后是完整正文：侧栏和正文标题旁都可复制，有译文先读、先复制中文；下方展开「英文原文」可单独复制英文。复制保留原字段的换行和缩进，不拼入来源或按钮文字。正文后依次是怎么用、摘要（若提供）、适用场景、来源。

仍支持确实缺正文的数据：侧栏主动作变为「查看原文」，标题区标「仅摘要」，摘要框内附出处外链；接着列场景和可选用法，不再重复来源章节，也不提供正文复制。

**Skill。** 用途之后先给安装，命令按数据原序逐条显示适用工具、等宽命令和可选说明。每条独立复制，只取命令，不执行它。接下来按有无数据列示例、运行依赖、摘要，再列适用场景及来源。不加载或展示技能文件全文。

「示例」只用作者提供的材料（决策 67，#35），无示例不显示标题。`SkillExamples.vue` 可列说明、请求、回答和节选标记；请求可单独复制。英文配译文时默认展示中文、复制中文请求，原文可展开对照。按材料附图、演示视频或示例文件链接，每例独立列来源和权利说明，不用站方编写的演示代替。

## 四、可见文字与待拍板项

| 原问题 | 现行结论 |
|---|---|
| 是否显示「最新收录」「标题」？ | 不显示。顺序固定，不接受排序参数（决策 47）。 |
| `/` 属于哪个搜索？ | 两库列表优先聚焦本库（决策 48）；全站快捷键仍开面板，面板现已纳入两库（决策 71）。保留桌面键帽。 |
| 复制失败如何提示？ | 实现已采用「未复制」，与「复制」「已复制」构成三态，行为见下表。不是待选文案。 |
| 「仅摘要」由许可决定吗？ | 不由许可决定；这是没有正文时的退路，有译文则中文优先（决策 63）。 |

上述界面没有悬而未决的选项。另一个尚未决定的问题是是否在页面放面向 AI 助手的收录库安装入口（决策 70）；它不是当前页面的控件。

## 五、视觉与状态基线

布局以 `site/.vitepress/theme/styles/library.css` 为准。1280px 下版心 1140px，刊头 280px，间距 100px，阅读或列表区 760px。桌面刊头吸顶；无框条目以分隔线分行，分类的色与图形由 `LibraryTile.vue` 和 `site/.vitepress/theme/library-marks.ts` 共用。列表「全部」不加环境色光，选类或进详情才有。820–1023px 刊头缩至 232px、间距 56px；1023px 及以下不显示行尾作者。小于 820px 时刊头在上、不吸顶，两边各留 24px，分类条自身横滑，行砖从 48px 缩至 40px。手机详情视觉次序为返回、分类砖、标题、操作、内容、属性，不把属性挡在正文前面。

| 控件 | 键盘、触摸及反馈 |
|---|---|
| 搜索 | 悬停加深边线，聚焦描整框并隐藏键帽；粗指针或小于 768px 不显示键帽。菜单打开、正在组词或编辑文本时不抢 `/`。框内 Esc 清查询、保留分类和焦点。 |
| 分类与条目 | 分类按钮以 `aria-pressed` 标记唯一选中项，零项不禁用。链接用 Enter，按钮用 Enter 或空格，Tab 移动不等于激活；搜索框和条目主链接有 2px 焦点描边。 |
| 展开与收起 | 按钮指向受控文本并反映展开状态，两态切换后焦点移到对应开关。长文工具条贴近视口底部，阅读中段也能复制。 |
| 复制 | `LibraryCopy.vue` 写剪贴板成功才换对勾和「已复制」；失败或接口不可用，选中完整目标文本以便手动复制，显示叉号和「未复制」。状态可播报，1800ms 后复位；每个按钮独立，再点重置本按钮计时。手机列表用图标保留可访问名。 |

浅深主题均保留焦点和文字反馈；面板的分类标签选中前后对比度均至少 4.5:1。启用减少动态效果时停用库页过渡、动画和按压变形，收起回行首不用平滑滚动。

**埋点（决策 72）。** 展开记 `prompt_open`，收起不记；复制结算后记 `prompt_copy` 或 `skill_copy` 并区分成功与失败、入口与语言或命令与示例，不把剪贴板内容作为属性。切类记 `filter` 和结果数；本库查询停手 1.5 秒或离开时发送待报的非空 `library_search`，连续相同词和分类不重复记。面板搜索另记 `search`，作者、许可、出处等出站点击记 `outbound`。字段与隐私口径见 [TRACKING.md](TRACKING.md)。
